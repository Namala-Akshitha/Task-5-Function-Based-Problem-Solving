# Data Science Internship – February 2026
## Task 5: Function-Based Problem Solving

### Overview
This repository contains my solutions for Task 5 of the Data Science Internship – February 2026. The assignment focuses on applying Python functions, conditional statements, loops, lists, sets, and mathematical operations to real-world problems.

### Problems Solved

1. **Social Media – Post Engagement Analyzer:** Calculates total likes and classifies post engagement.
2. **Healthcare – Medicine Stock Alert System:** Checks medicine stock and identifies low-stock conditions.
3. **Agriculture – Rainfall Adequacy Checker:** Calculates average rainfall and evaluates adequacy.
4. **Social Media – Duplicate Account Detection:** Identifies duplicate usernames using sets.
5. **Healthcare – Appointment Eligibility Checker:** Checks appointment eligibility based on age.
6. **Agriculture – Premium Crop Price Filter:** Filters crop prices above ₹2,000.
7. **System Monitoring – Application Health Checker:** Classifies system health based on error count.
8. **Banking – Daily Transaction Limit Checker:** Validates transactions against a ₹50,000 daily limit.
9. **E-Learning – Student Attendance Eligibility System:** Calculates attendance percentage and checks exam eligibility.
10. **Smart Electricity Bill Analyzer:** Calculates electricity charges using progressive pricing slabs and classifies usage.

### Technologies Used
- Python 3
- Jupyter Notebook / Google Colab
